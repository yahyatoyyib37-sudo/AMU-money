# AMU-money
This code is designed to discover and analyze halal online income opportunities, including freelancing, remote work, digital services, e-commerce, affiliate marketing, and ethical business models. Its goal is to help users find legitimate, sustainable, and Shariah-compliant ways to earn money online.

## Dashboard

Open [Halal-Income-Enhanced.html](Halal-Income-Enhanced.html) in a modern browser, or serve this directory with `python -m http.server 8765`. The application is self-contained and has no build step or runtime dependencies.

See [setup and usage](SETUP.md) and [implementation, validation and limitations](VALIDATION.md). Browser regression tests are in [tests](tests/).
